# Living Word Stories

A mobile-first Bible story app, kept separate from REVEALED.

## First episode

**The Donkey Who Saw the Angel** is a five-scene dramatized paraphrase of Numbers 22:21–35. The original character illustrations, scene animation, dialogue, camera movement, and transcript are all in `index.html`.

## No paid services required

The app is a static HTML/CSS/JavaScript page with no runtime AI API, paid voice service, or third-party JavaScript library. Narration uses the browser/device speech engine when available.

## Enable the public website

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. GitHub Pages will publish `index.html` at `https://awemissions.github.io/living-word-stories/` after the deployment finishes.
